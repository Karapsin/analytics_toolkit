# All Datetime Functions

Use `from analytics_toolkit import datetime as dttm` in user-facing code.
General timestamp helpers are listed before comparison and boundary helpers.

## General Functions

- [format_datetime](format-datetime.md) - format timestamps as `YYYY-MM-DD HH:MM:SS`
- [sanitize_datetime](sanitize-datetime.md) - format timestamps as `YYYYMMDDHHMMSS`
- [gen_datetimes_list](gen-datetimes-list.md) - build timestamp sequences
- [add_seconds](add-seconds.md) - add or subtract seconds
- [add_minutes](add-minutes.md) - add or subtract minutes
- [add_hours](add-hours.md) - add or subtract hours
- [add_days](add-days.md) - add or subtract days
- [add_weeks](add-weeks.md) - add or subtract weeks
- [add_months](add-months.md) - add or subtract months
- [add_quarters](add-quarters.md) - add or subtract quarters

## Comparison Functions

- [is_greater](is-greater.md) - compare whether one timestamp is after another
- [is_less](is-less.md) - compare whether one timestamp is before another
- [is_between](is-between.md) - check whether a timestamp falls within a range
- [seconds_between](seconds-between.md) - count whole seconds between timestamps
- [minutes_between](minutes-between.md) - count whole minutes between timestamps
- [hours_between](hours-between.md) - count whole hours between timestamps
- [days_between](days-between.md) - count whole days between timestamps

## Boundary Functions

- [datetime_bounds](datetime-bounds.md) - return timestamp period boundaries
- [is_period_start](is-period-start.md) - check whether a timestamp starts a period
- [is_period_end](is-period-end.md) - check whether a timestamp ends a period

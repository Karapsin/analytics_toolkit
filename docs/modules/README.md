# Module Documentation

This folder contains one folder per public module:

- [SQL](sql/index.md)
- [AB utilities](ab_utils/index.md)
- [Excel helpers](excel/index.md)
- [Date helpers](dates/index.md)

Open the module folder's `index.md` first. It is the navigation page for that
module and links to the separate section files.

Each major section lives in its own file so the docs stay easy to scan and edit.

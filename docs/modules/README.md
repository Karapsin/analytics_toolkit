# Module Documentation

This folder contains one folder per public module:

- [SQL index](sql/index.md)
- [SQL formatting index](sql_format/index.md)
- [AB utilities index](ab_utils/index.md)
- [Excel helpers index](excel/index.md)
- [Date helpers index](dates/index.md)
- [Datetime helpers index](datetime/index.md)

Open the module folder's `index.md` first. It is the navigation page for that
module. Each module index links to its function reference first and then to
workflow guides.

In individual module folders, use `functions/index.md` for function signatures
and input defaults. Each major workflow section lives in its own file so the
docs stay easy to scan and edit.

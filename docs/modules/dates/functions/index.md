# All Date Functions

Use `from analytics_toolkit.dates import ...` in user-facing code. General
reporting helpers are listed before less common helpers. Within each section,
the helpers most likely to be used in normal workflows appear first.

## General Functions

- [gen_dates_list](gen-dates-list.md) - build date sequences
- [first_day](first-day.md) - return the period start
- [last_day](last-day.md) - return the period end
- [add_days](add-days.md) - add or subtract days
- [add_weeks](add-weeks.md) - move by whole weeks
- [add_months](add-months.md) - move by whole months
- [add_quarters](add-quarters.md) - move by whole quarters
- [sanitize_date](sanitize-date.md) - format dates as `YYYYMMDD`

## Other Functions

- [get_today](get-today.md) - return today's date
- [get_random_day](get-random-day.md) - sample a date from a range
